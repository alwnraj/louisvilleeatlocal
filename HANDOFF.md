## What changed
1. Fonts self-hosted and subset (`fonts/`, `vercel.json` immutable rule).
2. Data split: `places.<hash>.js` (columnar, first view) + `detail.<hash>.json` (notes, sources, status links, fetched after map idle). Generated by `python3 -I scripts/build.py`; README updated.
3. Map style baked into `index.html` by `python3 -I scripts/make_style.py` (no runtime fetch/restyle, no sprite, 55 -> 35 layers).
4. Startup: lazy search text/ids, first 40 list rows then idle fill to 250, no id-list pin filter when unfiltered, `crossSourceCollisions:false`, glyph ranges requested when the library arrives, dead header-art code removed.
